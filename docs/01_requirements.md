## 要件定義
### アプリケーション概要
スイーツ向けのモバイルオーダーアプリケーションを想定

### 使用技術
`フロントエンド`<br>
　React<br>
　Vite<br>
　React Router<br>
　CSS<br>

`バックエンド`<br>
　Spring Boot<br>
　Spring Security<br>
　Spring Data JPA<br>
　MySQL<br>

`開発補助`<br>
　Docker Compose<br>
　npm<br>
　Node.js<br>
　Maven<br>

### ユーザーの種類
`一般ユーザー`<br>
　商品を選択できる<br>
　商品をカートに追加できる<br>
　注文確認画面で受け取り日時を選択できる<br>
　注文を確定できる<br>
　注文状況を確認できる<br>
　注文履歴を確認できる<br>
　注文した商品に評価を登録できる<br>
　アカウント情報を管理できる<br>
　パスワードを変更できる<br>

`管理者ユーザー`<br>
　商品を登録できる<br>
　商品を編集できる<br>
　商品を削除できる<br>
　商品の公開 / 非公開を切り替えできる<br>
　注文状況を確認できる<br>
　注文ステータスを更新できる<br>
　キャンセル理由を登録できる<br>
　ユーザーを管理できる<br>
　ユーザー管理番号を発行できる<br>
　管理者ユーザーを追加できる<br>
　注文評価を確認できる<br>
　注文分析を確認できる<br>
