# 要件定義
この資料はモバイルオーダーアプリの要件定義として<br>
アプリ概要、使用技術、ユーザー種別を整理したものです。

## 1. アプリケーション概要
スイーツ店向けのモバイルオーダーアプリケーションを想定

## 2. 使用技術
フロントエンド:
- React
- Vite
- React Router
- CSS

バックエンド:
- Spring Boot
- Spring Security
- Spring Data JPA
- MySQL

開発補助:
- Docker Compose
- npm
- Node.js
- Maven

## 3. ユーザーの種類
本アプリケーションでは主に2種類のユーザーを扱う

一般ユーザー:
- 商品を選択できる
- 商品をカートに追加できる
- 注文確認画面で受け取り日時を選択できる
- 注文を確定できる
- 注文状況を確認できる
- 注文履歴を確認できる
- 注文した商品に評価を登録できる
- アカウント情報を管理できる
- パスワードを変更できる

管理者ユーザー:
- 商品を登録できる
- 商品を編集できる
- 商品を削除できる
- 商品の公開 / 非公開を切り替えできる
- 注文状況を確認できる
- 注文ステータスを更新できる
- キャンセル理由を登録できる
- ユーザーを管理できる
- ユーザー管理番号を発行できる
- 管理者ユーザーを追加できる
- 注文評価を確認できる
- 注文分析を確認できる
